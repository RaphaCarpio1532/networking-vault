# Ping

## 🇬🇧 English
Sends ICMP echo requests to test if a host is reachable and measure latency. First step in almost every help-desk diagnosis. `ping 8.8.8.8` tests internet; `ping google.com` also tests [[DNS]].

## 🇮🇹 Italiano
Invia richieste ICMP per verificare se un host è raggiungibile e misurare la latenza. Primo passo in quasi ogni diagnosi help-desk. `ping google.com` testa anche il [[DNS]].
