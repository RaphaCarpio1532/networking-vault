# nslookup and dig

## 🇬🇧 English
DNS query tools. `nslookup google.com` (Windows/all) and `dig google.com` (Linux/macOS, more detailed) resolve names to IPs and check record types (A, MX, NS). First stop when [[DNS]] is suspected.

## 🇮🇹 Italiano
Strumenti di query DNS. `nslookup` e `dig` risolvono i nomi in IP e controllano i tipi di record (A, MX, NS). Prima tappa quando si sospetta un problema [[DNS]].
