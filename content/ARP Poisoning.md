# ARP Poisoning

## 🇬🇧 English
Sending forged [[ARP]] replies so traffic for a target IP is sent to the attacker's [[MAC Address]] instead — the classic way to set up [[Man in the Middle]]. Defense: dynamic ARP inspection, static entries, [[Network Segmentation]].

## 🇮🇹 Italiano
Inviare risposte [[ARP]] falsificate così che il traffico verso un IP venga inviato al [[MAC Address]] dell'attaccante — il modo classico per fare [[Man in the Middle]]. Difesa: dynamic ARP inspection.
