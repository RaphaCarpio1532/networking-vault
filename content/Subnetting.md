# Subnetting

## 🇬🇧 English
Dividing one large network into smaller sub-networks using a **subnet mask** (e.g. 255.255.255.0). Improves performance and security by isolating segments (see [[Network Segmentation]]). The mask decides which bits are network and which are host.

## 🇮🇹 Italiano
Dividere una rete grande in sotto-reti più piccole tramite una **subnet mask** (es. 255.255.255.0). Migliora prestazioni e sicurezza isolando i segmenti (vedi [[Network Segmentation]]).
