# CIDR Notation

## 🇬🇧 English
A shorthand for the subnet mask written as `/n`, where n is the number of network bits. Example: `192.168.1.0/24` = mask 255.255.255.0 = 256 addresses. `/16` is bigger, `/30` is tiny (point-to-point links).

## 🇮🇹 Italiano
Una scrittura abbreviata della subnet mask come `/n`, dove n è il numero di bit di rete. Esempio: `192.168.1.0/24` = maschera 255.255.255.0 = 256 indirizzi.
