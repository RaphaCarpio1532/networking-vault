# SSH

## 🇬🇧 English
**Secure Shell** (port 22) gives an encrypted command-line connection to remote machines, replacing insecure Telnet. Supports password or key-based auth (keys are stronger). Also used for secure file transfer (SCP/SFTP) and tunneling.

## 🇮🇹 Italiano
**Secure Shell** (porta 22) offre una connessione a riga di comando cifrata verso macchine remote, sostituendo l'insicuro Telnet. Supporta autenticazione con password o chiavi (più sicure).
