# HTTP and HTTPS

## 🇬🇧 English
**HTTP** (port 80) carries web traffic in plaintext. **HTTPS** (port 443) wraps it in [[TLS and SSL]] for confidentiality and integrity. Always prefer HTTPS; plaintext HTTP is readable via [[Packet Sniffing]].

## 🇮🇹 Italiano
**HTTP** (porta 80) trasporta traffico web in chiaro. **HTTPS** (porta 443) lo cifra con [[TLS and SSL]]. Preferire sempre HTTPS; l'HTTP in chiaro è leggibile tramite [[Packet Sniffing]].
