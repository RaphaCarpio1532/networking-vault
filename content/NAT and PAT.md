# NAT and PAT

## 🇬🇧 English
**NAT** (Network Address Translation) lets many private IPs share one public IP. **PAT** (Port Address Translation, aka overload) adds port numbers so many devices use one public IP at once — the most common home/office setup. Also hides internal addresses, a mild security benefit.

## 🇮🇹 Italiano
**NAT** permette a molti IP privati di condividere un IP pubblico. **PAT** aggiunge i numeri di porta così molti dispositivi usano un IP pubblico insieme. Nasconde anche gli indirizzi interni.
