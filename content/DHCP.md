# DHCP

## 🇬🇧 English
**Dynamic Host Configuration Protocol** automatically assigns IP address, subnet mask, gateway and [[DNS]] to devices. Process = DORA (Discover, Offer, Request, Acknowledge). A rogue DHCP server is a common attack — a frequent help desk troubleshooting point.

## 🇮🇹 Italiano
**Dynamic Host Configuration Protocol** assegna automaticamente IP, subnet mask, gateway e [[DNS]] ai dispositivi. Processo = DORA. Un server DHCP malevolo è un attacco comune.
