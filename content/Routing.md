# Routing

## 🇬🇧 English
The process of choosing a path for packets across networks. **Static** routes are set manually; **dynamic** routing protocols (OSPF, BGP, RIP) learn paths automatically. The router's routing table is the decision source.

## 🇮🇹 Italiano
Il processo di scelta del percorso dei pacchetti tra le reti. Le rotte **statiche** sono manuali; i protocolli **dinamici** (OSPF, BGP, RIP) imparano i percorsi automaticamente.
