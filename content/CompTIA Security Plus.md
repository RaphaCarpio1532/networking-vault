# CompTIA Security Plus

## 🇬🇧 English
The baseline cybersecurity certification. Covers threats, [[Encryption]], [[Access Control]], [[Network Security Fundamentals]], risk and incident response. Widely required for junior security roles.

## 🇮🇹 Italiano
La certificazione di base in cybersicurezza. Copre minacce, [[Encryption]], [[Access Control]], [[Network Security Fundamentals]], rischio e risposta agli incidenti. Molto richiesta per ruoli junior di sicurezza.
