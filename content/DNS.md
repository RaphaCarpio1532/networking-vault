# DNS

## 🇬🇧 English
**Domain Name System** translates names (google.com) into IP addresses. Uses UDP/TCP port 53. Critical and frequently attacked: DNS spoofing/cache poisoning, tunneling. DNSSEC adds integrity. Tools: [[nslookup and dig]].

## 🇮🇹 Italiano
**Domain Name System** traduce i nomi (google.com) in indirizzi IP. Usa la porta 53. Critico e spesso attaccato: spoofing/cache poisoning, tunneling. DNSSEC aggiunge integrità.
